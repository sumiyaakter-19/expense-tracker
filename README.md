# Expense Tracker

A simple command-line expense tracker built with Python.
Your data is saved in a file, so it stays after you close the program.

## Features
- Add an expense (title, amount, category)
- View all expenses
- See total spending and total by category
- Delete an expense

## How to run
1. Install Python 3
2. Download `expense_tracker.py`
3. Run: `python expense_tracker.py`

## What I learned
- File handling with JSON
- Functions, loops and dictionaries
- Handling wrong input with try/except
